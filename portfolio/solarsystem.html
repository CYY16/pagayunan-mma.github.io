Solar System

A look at the solar system and all of its planets, built as a 3D model

Project Overview

This project is a 3D animated model of our solar system. It features the Sun and the orbiting planets, along with details like atmospheric lighting and Saturn's rings. The planets are set against a deep space background filled with stars, nebulas, and moving elements like rockets and shooting stars.

Tools Used

Blender 5.1.1

Render Time

3 hours 15 minutes

Resolution

1280 x 720

Step-by-Step Tutorial

1 / 5

Open Blender and Create a New File

Launch the Blender application on your computer. On the splash screen, select General under New File to open a clean workspace.

Switch to the Scripting Workspace

Look at the top menu bar and click Scripting. In the Text Editor panel, click New to create a new script.

Paste and Run Your Code

Click inside the text area and paste or type your Python code, then run it.

Adjust Viewport and Settings

Switch back to the Layout or Modeling workspace to see your generated objects. Adjust your camera view, framing, and light settings based on your preference.

Render the Final Scene

Select Render Image, or press F12, for a single frame. Select Render Animation, or press Ctrl + F12, if your script created a moving scene.
