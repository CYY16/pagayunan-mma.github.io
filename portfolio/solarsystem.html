Solar System

A 3D model of the solar system with all planets rendered in Blender.

Project Overview

This solar system model combines artistic visualization with scientific accuracy. Each celestial body is rendered in 3D with realistic proportions and orbital characteristics.

Tools Used

Blender 5.1

Render Time

Custom render settings

Resolution

1280 x 720
